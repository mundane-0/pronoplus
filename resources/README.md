# Ressources ProNote+

Icônes nécessaires:
1. icon.icns - macOS (512x512)
2. icon.ico - Windows (256x256)
3. icon.png - Linux (512x512)

Pour générer les icônes:
- Sur macOS: utiliser Icon Composer ou sips
- Sur Windows: utiliser ICO Convert
- Sur Linux: utiliser GIMP ou Inkscape

Pour le moment, nous utilisons des icônes par défaut.
